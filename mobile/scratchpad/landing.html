Digit landing

Rises 22 and fades over 380ms, cubic ease-out along a linear run. Each character is its own cell keyed by identity, so only a genuinely new one mounts, and it animates because it mounted. The re-centring glide is additive: type again before it finishes and the new push adds to the travel still left. Both old bugs are toggleable — the second one is the lurch you were seeing from the third digit on.
